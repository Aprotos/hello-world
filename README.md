## Learning to Code

This repo also contains beginner coding examples. See `hello.py` for a walkthrough of the core concepts:

| Concept | What it does |
|---|---|
| **Print** | Output text to the screen |
| **Variables** | Store data (text, numbers, true/false) |
| **Strings** | Work with text |
| **Math** | Add, subtract, multiply, divide, etc. |
| **Lists** | Store ordered collections of items |
| **If/Else** | Make decisions based on conditions |
| **For loops** | Repeat code for each item in a list |
| **While loops** | Repeat code while a condition is true |
| **Functions** | Write reusable blocks of code |
| **Dictionaries** | Store key-value pairs (like a lookup table) |

### Running the example

```bash
python3 hello.py
```
